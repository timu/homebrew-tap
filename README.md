# Homebrew tap

Homebrew formulae by [@timu](https://github.com/timu).

```sh
brew install timu/tap/toneoff
```

Homebrew requires explicit trust for third-party taps. Installing by the full name above trusts just that one formula. If you `brew tap timu/tap` first and want to use the short name `toneoff`, trust the formula once with `brew trust --formula timu/tap/toneoff`.

| Formula | Description |
| --- | --- |
| [toneoff](https://github.com/timu/toneoff) | Menu bar app that turns True Tone off while external displays are connected |
